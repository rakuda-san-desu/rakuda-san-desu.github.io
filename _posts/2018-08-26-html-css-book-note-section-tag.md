<h3>セクションタグ</h3>
<h4>セクションタグの種類</h4>
<strong>article（(~についての）記事）</strong>

そのまとまりで完結する内容、記事、エントリーなど

<strong>aside (別途、予備)</strong>

補足情報や広告など

<strong>nav(ナビゲーション、誘導）</strong>

サイトのナビゲーション（ページ内外へのリンク）

<strong>section(分割された部分、区切り）</strong>

上記のどれにも当てはまらないセクション

<span style="font-weight: bold;">セクションとは？</span>

HTMLでは文章を区切って分類する為に付けるもので、レイアウトの為に使うタグではないようです。

コンピューターに内容を示すための手助けや、ソースを読むときの可読性アップのために付けるって認識でいいのかな？

ネットで解説を読むと

・（基本的に）レイアウトの為に使用するタグではない

・セクションタグの中には見出しを入れる

と言うルールもある様です。
